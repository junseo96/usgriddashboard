# Grid Atlas — 새 프로젝트

2026-10-08 사용자가 기존 대시보드를 참고 자료로만 두고 별도 사이트를 구축하도록 요청함. 이 디렉터리가 새 애플리케이션 루트이며 상위 AGENTS.md의 기존 Site 유지·기존 UI 확장 지침은 이 새 프로젝트에 적용되지 않음. 기존 앱·Site·데이터는 그대로 보존.

- React/TypeScript 프런트엔드, Cloudflare Worker + D1 API. 로컬은 동일 SQL 스키마와 Node SQLite 어댑터 사용.
- 공식 출처·원자료 기준일·실제 수집시각을 분리. 미공개 MW는 null, 집계/사례는 개별 원장과 분리. 본토 48주/DC, 활성 신청, 동일 ID 기준 집계. 물리 프로젝트 식별 미완료를 숨기지 않음.
- 확인된 미진행은 요건별 최대 20점. 미공개/미확인은 별도 집계. 뉴스 추정은 근거·이유·실제 적용일이 필수. 모든 요건을 알 때만 평균 점수에 포함.
- 2026-10-09 사용자가 공식 원장 진행단계로 개별 추정 점수와 평균 산출을 요청했다. `stage-proxy-v1`은 직접 근거 평가와 분리된 단계 모형이다. 단계별 다섯 진행률은 가정으로 명시하고 공식 확인으로 저장하지 않는다. 단계가 불명확하면 미산출, 직접 요건 근거가 하나라도 선택되면 단계 추정을 억제한다. 화면 평균·CSV는 직접 점수를 우선하며 추정 포함 여부·분모를 함께 표시한다.
- 관측과 평가 이력은 추가 저장. 과거 자료가 없는 날짜는 자료 없음. 당시 알려진 범위와 현재 근거로 재평가한 과거를 구분.
- 데이터셋의 전국 완전성을 보장하지 않음. 수집 성공·정규화 완료·평가 완료·자동 일정 가동을 각각 표시.
- 권역별 수용가 대표 지표는 `data/regional-pipeline-coverage.json`의 검토된 출처를 사용한다. 회사별 부분 집계·누적 요청·계약·송전계획 지원 부하를 권역 전체 신청 총량으로 바꾸거나 서로 합산하지 않는다. NYISO 개별 원장 용량을 전국 수용가 규모로 표시하지 않는다.
- 운영 쓰기에는 ADMIN_TOKEN 인증 필요. 비밀값은 브라우저 번들·저장소·로그에 포함하지 않음. 평가 테스트는 별도 DB에서 실행.
- GitHub Pages 조회용 사이트와 15분 목표의 실측 부하 수집을 사용한다. 평가 저장·DB 운영은 별도 Cloudflare 설정이 필요하다. 테스트 통과와 설정 파일 작성만으로 배포·예약 실행 완료를 주장하지 않음.

- 2026-10-12 사용자는 NYISO 중심을 벗어나 전국 데이터센터·대형 제조시설의 발표·계획·건설·운영·중단을 먼저 폭넓게 수집하고 접속 근거를 나중에 연결하도록 요청했다. `large-load-facilities.json`은 이 시설·개발 원장이고 기존 접속 원장과 분모가 다르다. MW·계통 신청 증거 미확인만으로 실제 시설을 제외하지 않는다.
- 같은 요청에서 진행 정보가 없는 시설에도 보수적 임의 점수를 허용했다. 시설 진행 모형·주/ISO 절차 참고 가정·규정 미연계 공통 절차 가정을 구분하고, 낮은 신뢰도·가정·점수 범위를 표시한다. 이는 앞선 미확인 단계 미산출 원칙에 대한 시설 원장의 명시적 예외다. 규정 존재나 목표기간 경과를 완료 증거로 만들지 않으며 현재 가정을 과거에 소급하지 않는다.

- 2026-10-13 사용자 요청: 기본 병목 평균은 용량 가중(`Σ점수×MW / ΣMW`)이고 건수 평균은 보조값이다. 유형 필터는 해당 유형 MW를 사용하며 전체 공개 성분 합은 물리 접속점 용량으로 부르지 않는다. 원자료·개별 점수·관측 이력은 보존하고 과거 평균은 당시 MW로 재계산한다. 용량/점수 누락과 0 MW를 구분한다. 시설 요청·계약·시설 전력은 기준별로 분리한다. `docs/CAPACITY_WEIGHTING.md` 참조.
- 실제 송배전 제약은 별도 메뉴의 송전/배전 화면으로 구분한다. 정전 신뢰도는 혼잡의 직접 측정값이 아니고, hosting capacity는 실제 여유의 특정 시나리오다. 공개되지 않은 전국 혼잡률이나 선로 여유를 추정해 관측값으로 표시하지 않는다.
