# 수용가 파이프라인의 범위와 해석

전국 개요와 부하 비교에 표시하는 7개 권역 대표 지표는 [REGIONAL_LOAD.md](REGIONAL_LOAD.md)를 참고한다. ERCOT 전체 요청·유틸리티 부분 집계·MISO 송전계획 지원·NYISO 개별 원장을 구분하며, 서로 더해 전국 수용가 총량으로 만들지 않는다. 기존 48개 집계에 NYISO 활성 원장 요약, ISO-NE 선별 2건, 10월 7일 MISO 권고 포트폴리오, ERCOT 9월 조건부 Base 분류를 추가해 현재 52개다.

기존 화면의 수용가 53건은 미국 전체의 데이터센터·공장 수가 아니다. 2026-10-08 취득한 NYISO `Load Projects` 공개 원장 74행 중 현재 활성으로 검증된 행 수다. 다른 지역은 고객별 신청 명부의 공개 범위·상태 정의·전력용량 단위가 달라 같은 점수 분모로 바로 합칠 수 없었다. 이번 공개 탐색 자료는 이 차이를 유지하면서 빠져 보이던 실명 프로젝트, 전력회사 원장, 규제 계약 사건과 지역별 집계를 함께 보여준다.

`public/data/load-pipeline.json`은 980개 출처·사례 행과 52개 별도 집계로 구성된다. **980개는 활성 대기 프로젝트 수가 아니다.** 운영·철회·익명 행·계약 사건·송전 지원도 명시적으로 포함한다. 동일한 물리 사업의 다른 문서와 재신청을 연결하는 작업은 미완료다.

실명 자료 44건에는 Stargate Abilene, IREN Childress, Google Van Buren, Oracle Saline, Meta Hyperion, Samsung Taylor, Toyota NC, Rivian Georgia, Ford Tennessee, Novelis·Nucor·Wolfspeed·수소 사업 등이 포함된다. 추가 계약 자료에는 Micron Idaho와 Chobani도 있다. 산업용량이 미공개여도 사례를 삭제하지 않는다. NYISO Micron Fab 2·3 등 기존 신청 행은 `linkedProjectId`로 연결하며 다시 더하지 않는다. AWS Northern Indiana는 복수 캠퍼스 묶음이므로 단일 프로젝트 대신 집계에 둔다. Alaska 사례는 본토 범위에서 제외한다.

PJM M-3, MISO 송전계획, SPP DPA의 기존 자료는 별도 기록 수 집계로 노출한다. 2,447개의 SPP 과거 예비평가를 신규 수용가 2,447개로 늘리거나 상세 검색의 기본 목록을 과거 기록으로 채우지 않는다.

## 용량의 구분

- `requested_grid_mw`: 문서에 명시된 계통·소매서비스 요청 부하. 실측 수요와 다르다.
- `contracted_grid_mw`: 계약 관련 고객 수요. 조건부 계약과 최종 전력공급 확약, 통전 여부를 따로 확인한다.
- `site_power_mw`: 부지 총전력·최종 개발 전력규모. 기존 운영 부분이나 향후 확장을 포함할 수 있다.
- `it_mw`: 서버 등 critical IT 부하. 냉각·부대시설 전력을 포함한 계통 인출량으로 합산하지 않는다.
- `generation_mw`: 현장 전원 설비. Project Jupiter 연료전지는 수용가 계통 요청이 아니다.
- `mixed_mw`: 요청·연구·계약·운영 등 서로 다른 단계나 정의를 섞은 원문 집계.
- `unknown`: 비교 가능한 용량이 확인되지 않아 `capacityMw: null`.

MVA에 임의 역률을 곱하지 않으며, 전해조 정격·배터리 생산 GWh·투자액·과거 산업부하 전망을 현재 시설의 신청 MW로 바꾸지 않는다. Meta의 5 GW `compute capacity`도 전기 IT 부하인지 불분명해 비교 용량은 null로 둔다. 알려진 원문 숫자와 기준은 설명문에 보존한다.

Google 5079 Disk Drive는 CPUC 자료가 2025-03-03 230 kV 소매서비스 신청과 전면 개발 시 250 MW를 명시하므로 신청 사례로 분류한다. 공개 큐 ID가 없고 기존 원장과의 연결이 미확정이므로 기존 점수 분모에는 추가하지 않는다. 결의안 E-5455는 초안·안건이며 최종 승인 근거가 아니다. 2026-10-08 미국 태평양 11시 회의는 한국 10월 9일 03시로, 이번 확인 당시 표결 전이다.

## 왜 지역 집계가 개별 행보다 큰가

아래는 전국 합계로 더할 수 없는 서로 다른 모집단의 예다. 원문 기준일과 실제 확인일을 함께 표시한다.

| 원문 공시 | 용량 | 주의 |
| --- | ---: | --- |
| ERCOT 2026-06-18 보도자료 | **438 GW 초과** 요청 | 약 89% 데이터센터. 추출 기준일 미명시. 모든 문의가 실제 건설되는 것은 아니다. |
| ERCOT LLWG 2026-06-18 기준 | 약 466.5 GW | 운영·미가동·연구 미제출을 함께 포함. 438 GW와 기준·범위가 달라 서로 더하지 않는다. |
| Oncor 2026년 6월 말 | 약 282 GW 데이터센터, **16 GW 초과** 기타 산업 | 전체 LC&I 요청은 737건. 데이터센터만 737개라는 뜻이 아니며 ERCOT과 중복된다. |
| PPL 2026-09-29 발표 | **240 GW 초과** 요청 | 2024년 9월 이후 누적 요청. 현재 순수 미통전·고유 고객 대기열이 아니다. |
| FirstEnergy 2026-09-29 | 102 GW 연구 요청 | 연구·계약·통전을 구별한다. |
| Exelon 2026-09-29 | 37 GW 파이프라인 | 약 12 GW 고확률·운영 부분집합 등과 중복된다. |
| SRP 2025-09-25 기준 | 15.308 GW 요청 | 80개 고객 프로젝트. 첨단제조 841 MW는 이 총량의 부분집합이다. |

이 자료는 “미국에 신청이 53개밖에 없다”는 해석이 틀렸음을 보여주지만, 지역 집계만으로 고객별 이름·단계·용량을 복원하거나 전국 프로젝트 평균 병목점수를 만들 수는 없다. 새로운 고객 원장·신원 연결·절차별 근거를 계속 확보해야 한다.

## 출처 확인과 재생성

2026-10-08 17:43 KST에 ERCOT·Oncor·CenterPoint·PJM 제출자료와 일부 기업·규제기관 원문 26 URL을 조회하여 24개를 취득·대조했다. DTE 자체 사이트와 PUCT PDF 2개는 취득 실패했다. Google Van Buren의 1 GW는 대신 SEC DTE 원문과 대조했다. 공개 출력의 재확인일은 실제 확인된 해당 주장에만 갱신했다. 나머지 자료는 기존 10월 3~4일 확인일을 그대로 유지한다. Samsung Taylor의 기존 6월 10일 날짜는 현재 공식 본문이 제시한 10월 7일로 정정하고 근거를 기록했다.

`sourceAsOf`는 원문이 명시하는 기준일 또는 복수 근거로 확인한 상태의 기준일이며 월 단위 또는 null을 유지할 수 있다. `checkedAt`은 근거 확인일이다. `generatedAt`은 JSON을 조립한 시각이다. 재생성·사이트 재배포로 이 날짜들을 현재 자료인 것처럼 바꾸지 않는다.

```sh
python3 scripts/build-load-pipeline.py
python3 scripts/build-load-pipeline.py --check
python3 -m unittest discover -s tests -p 'test_pipeline.py'
```

빌더는 공개 저장소에 포함된 `data/bootstrap.json`과 코드 안의 검토된 공시 자료를 이용한다. 기존 보관 ZIP이나 네트워크가 없어도 재현된다. 네트워크 수집기는 아니며 점수 DB·평가·원장 적격 여부를 수정하지 않는다. 새 자료 반영 시 원문·단위·상태·중복 범위·실제 확인일을 검토해 공시 자료를 수정하고 다시 생성한다. 정기 실행에서 이 스크립트를 호출하는 것만으로 외부 자료가 자동 갱신되는 것은 아니다.

실제 원문 취득물과 SHA-256 보고서는 로컬 `.local/pipeline-research/`에 보존하며 원문 전체를 공개 저장소에 포함하지 않는다. 공개 JSON에는 원출처 링크와 필요한 사실·해석 한계를 제공한다.
