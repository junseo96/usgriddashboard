# 용량 가중 병목점수

2026-10-13 사용자의 요청으로 집계 기본값을 프로젝트 수 평균에서 용량 가중평균으로 변경했다. 개별 프로젝트의 다섯 절차 배점과 그 근거는 그대로 사용하고, 집계 모형만 `capacity-weighted-v1`로 구분한다.

`평균 = Σ(개별 점수 × 해당 시점의 공개 MW) / Σ(그 점수에 사용한 공개 MW)`

1,000 MW 사업 90점과 100 MW 사업 10점의 용량 평균은 82.7273점이다. 프로젝트 수 평균 50점은 보조값이다. MW를 GW로 바꿔도 점수는 같으며, 점수의 단위는 계속 0–100점이다.

## 원장과 용량 기준

- 발전·저장·수용가 개별 유형은 해당 유형의 MW만 가중치로 사용한다. 저장의 에너지 용량 MWh는 가중치가 아니다.
- 전체 유형에서는 공개된 발전·저장·부하 MW 성분을 같은 원장 ID 안에서 합산한다. 하이브리드 레코드는 한 번 집계하되 그 공개 성분이 가중치에 반영된다. 이는 **공개 설비·부하 용량**이고, 하이브리드의 공용 접속점 한도나 송전망 순수요가 아니다. 알 수 없는 접속점 한도를 합계 또는 최댓값으로 추정하지 않는다.
- 일부 성분만 알려진 사업은 그 공개 성분만 가중치에 반영하며, 누락 성분을 0 MW로 저장하지 않는다. 유형을 바꾸면 해당 유형의 공개 용량만 반영한다.
- 시설·개발 원장은 접속 원장과 다른 모집단이다. 요청 MW, 계약 MW, 시설 발표 전력 MW 등의 평균을 용량 기준별로 따로 계산한다. 서로 다른 용량 의미를 대체하거나 합산하지 않으며 IT 전력에 임의 PUE를 곱하지 않는다.
- 동일 시설의 여러 용량 주장, 단계와 전체 캠퍼스의 중복, 중복 후보와 식별 미완료는 별도 제외·검토 사유를 유지한다. 단순히 가장 큰 발표값을 선택하지 않는다.

## 포함과 제외

점수와 유효한 양수 MW가 모두 있는 적격 사업만 점수 분자와 분모에 함께 들어간다. 용량 미공개, 0 MW 공개, 점수 미산출은 구분한다. 점수 미산출 사업의 MW를 분모에만 넣어 평균을 낮추지 않는다. 원장·시설 목록에서는 제외하지 않고 평균 포함 여부와 분모 GW, 용량 미확인 건수, 점수 미확인 MW를 함께 표시한다.

시설 미확인 단계의 보수적 시나리오는 기존처럼 기본 평균에서 제외하고 선택적으로 포함한다. 운영·철회·취소 및 원장별 제외 규칙은 유지한다. 프로젝트 수 평균은 별도 보조값이며 MW 평균이 없는 경우 대신 대표값으로 표시하지 않는다.

## 과거 값과 관측 보존

LBNL·NYISO 과거 원장과 검토한 권역별 단계 집계를 해당 시점의 상태와 공개 용량으로 재계산한다. 당시 MW가 없으면 용량 평균은 미산출이며, 확보한 건수와 개별 점수는 보존한다. 현재 대형 캠퍼스 계획용량을 과거 초기 단계의 용량으로 소급하지 않는다.

기존 DB 관측은 수정하거나 삭제하지 않는다. 보존된 각 관측 원장을 읽을 때 현재 집계식을 적용하고 집계 버전을 표시한다. 시설 관측도 원자료 기준일·실제 취득시각·근거 이력을 유지한다. 현재 모형으로 재평가한 과거 값이며, 당시 발표된 공식 점수 또는 당시 시스템이 이미 알고 있던 값이라는 뜻은 아니다.

권역·출처·현재와 과거의 공개율이 다를 수 있다. 신규 대형 사업의 유입이나 용량 수정은 동일 사업의 절차 진척과 다른 원인이다. 개별 생애주기 점수, 건수·MW 시계열, 용량 가중 점수와 해당 분모를 함께 확인한다.

## 실제 송배전 제약과의 구분

절차 점수는 계통 연결에 필요한 잔여 절차를 나타낸다. 실제 선로 제약·가격 분리·배전 접속 여유는 별도 **송배전 제약** 메뉴에서 원단위와 출처로 확인한다. 물리적 송배전 상황을 프로젝트 인허가 점수로 대체하거나 둘을 하나의 점수로 합치지 않는다.
