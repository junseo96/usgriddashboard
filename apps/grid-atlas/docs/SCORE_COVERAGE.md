# 진행 단계별 병목점수

2026-10-09 사용자의 요청에 따라, 공개 원장의 진행 상태를 판단하여 개별 단계 추정 점수를 산출한다. 2026-10-13부터 기본 평균은 용량 가중으로 변경했고 프로젝트 수 평균은 보조값으로 보존한다. [집계식·분모·과거 재계산](CAPACITY_WEIGHTING.md)을 참조한다. 이 모형은 `stage-proxy-v1`이며, 요건별 직접 근거를 저장하는 `grid-atlas-v1` 평가와 분리한다. 구현은 `shared/stage-estimate.ts`와 `shared/scoring.ts`에 있다.

별도 **수용가 권역 비교**는 `load-stage-v1`으로 다른 권역의 검토된 단계 집계·선별 사업까지 평가한다. 프로젝트 수 또는 MW 가중치, 운영 포함 여부와 출처별 분모를 표시하며 아래 전국 개요의 개별 원장 평균에 합치지 않는다. [권역별 수용가 점수와 과거 비교](LOAD_BOTTLENECK.md)를 참조한다.

## 현재 원장에 적용한 결과

현재 평가 건수·평균·가중치 분모는 화면과 API에서 계산한다. `ratingMean`은 점수와 양수 공개 MW가 모두 있는 활성 적격 사업의 용량 가중값이다. `projectCountRatingMean`은 기존 프로젝트 수 평균이다. 용량 미공개·0 MW 공개·점수 미산출은 별도 집계한다.

이는 수집한 공개 원장의 평균이며 미국 전체 물리 프로젝트의 전수 평균은 아니다. 개별 수용가 접속 원장과 전국 시설·개발 원장은 모집단과 용량 의미가 달라 별도 집계한다. 회사별 총량·다부지 계약·권역 단계 집계를 개별 사업과 합산하지 않는다.

LBNL 발전·저장 원자료 기준일은 **2025-12-31**이다. NYISO 원장의 단일 기준일은 미공개이고, 실제 확인은 **2026-10-08**이다. 모형을 적용하거나 사이트를 빌드한 날짜를 프로젝트 진척도의 최신 확인일로 바꾸지 않는다.

## 요건별 배점과 해석

각 요건은 `20 × (1 − 모형 진행률)`로 계산하고 다섯 요건을 합산한다. 아래 비율은 원장 단계에 일관된 점수를 매기기 위한 **분석 가정**이다. 실제 공정률·인허가 취득률·완료 증빙이 아니며, 원장에 직접 없는 요건의 상태를 공식 확인으로 저장하지 않는다.

| 확인한 원장 단계 | 기술 | 계약·비용 | 인허가 | 공사·보강 | 통전 | 합계 점수 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Not Started / Scoping Meeting Pending | 0% | 0% | 0% | 0% | 0% | 100 |
| Feasibility Study | 25% | 25% | 0% | 0% | 0% | 90 |
| SRIS/SIS Pending | 50% | 25% | 0% | 0% | 0% | 85 |
| Cluster Study / System Impact Study / SRIS/SIS in Progress | 50% | 25% | 25% | 0% | 0% | 80 |
| SRIS/SIS Approved / FS Pending | 75% | 25% | 25% | 0% | 0% | 75 |
| Facility Study / FS in Progress | 75% | 50% | 25% | 0% | 0% | 70 |
| IA Pending / Accepted Cost Allocation/IA in Progress | 100% | 75% | 50% | 0% | 0% | 55 |
| IA Executed | 100% | 100% | 50% | 0% | 0% | 50 |
| Construction / Under Construction | 100% | 100% | 100% | 75% | 0% | 25 |

- 접수 후 범위 협의 대기만 확인되는 경우 접수 자체에 진행 점수를 주지 않는다. 초기 단계 100점 역시 다섯 요건 모두 미진행임을 직접 확인했다는 뜻은 아니다.
- NYISO `FS`는 **Facilities Study and/or ATRA**다. 초기 타당성 연구 `FES`와 혼동하지 않는다.
- 계약 체결은 인허가·공사 완료를 증명하지 않는다. 인허가 50% 등의 값은 모형 가정이며 실제 확인란은 그대로 미확인이다.
- 공사 중 75%는 측정한 공정률이 아니다. 착공·부분 통전·계약 변경 등의 구체적인 근거를 확인하면 요건별 직접 평가로 대체해야 한다.
- `active`, `In Progress (unknown study)`, `Suspended`, `Rejected Cost Allocation/Next FS Pending` 등은 단계가 충분히 특정되지 않아 미산출이다. 미공개를 자동으로 100점으로 만들지 않는다.
- LBNL·NYISO는 검토한 출처 ID, 공식 HTTPS 출처, 정확한 상태 문구에 적용한다. 추가 수용가는 검토 JSON의 프로젝트 전체 필드와 정확히 일치하고 명시된 단계 ID·판단 이유가 있는 경우에만 추정한다. 다른 출처의 비슷한 문구나 부정문을 자동으로 대응시키지 않는다. `In-progress`만 있고 상세 단계가 불명확하면 미산출이다.

자료에는 계약 체결·시설연구·공사 중·시작 단계 등 여러 진행단계가 포함된다. 따라서 미진행 프로젝트만 집계한 결과가 아니다. 자료 추가로 평균이 바뀐 것은 모집단의 변화이며, 기존 동일 프로젝트가 실제로 진척되었다는 시계열 변화와 구별한다.

점수는 단계가 얼마나 남았는지를 비교하는 지표다. 체류 기간, 비용, 지연 확률이나 통전 성공 확률을 직접 측정하지 않으며 이 배점은 통계적으로 보정된 예측모형이 아니다. 점수를 낮추기 위해 근거 없는 상태 변화를 만들지 않는다.

## 직접 근거와 추정의 우선순위

1. 다섯 요건의 직접 근거 평가가 모두 있으면 해당 점수를 사용한다. 뉴스 등에 근거한 개별 정성 평가는 근거 URL·적용일·확인시각·판단 이유가 있어야 한다.
2. 선택된 요건별 근거가 전혀 없을 때만 단계 모형을 사용한다. 부분 근거 또는 명시적 미확인 정정이 하나라도 있으면 단계 모형으로 덮어쓰지 않는다.
3. 단계도 불명확하면 점수는 null이다. 기본 평균은 점수와 양수 공개 MW가 있는 적격 신청의 점수×MW 합을 해당 MW 합으로 나눈다. 프로젝트 수 보조 평균, 미산출 수, 용량 누락, 추정 포함 수를 표시한다.

API의 `pointMean`·`point`는 기존 직접 근거 점수이고 `ratingMean`·`stageEstimate`는 화면에서 쓰는 점수의 별도 표현이다. CSV는 기존 `bottleneck_score`를 보존하면서 `rating_score`, `rating_basis`, `rating_model_version`, `raw_status`, `stage_model_rationale`를 추가한다. 원문·출처·원자료 기준일은 각 행에 남긴다.

## 과거 시점과 정기 갱신

과거 관측이 있으면 그 관측에 저장된 원문 상태에 같은 모형을 적용한다. 이는 현재 모형으로 과거를 재평가한 값이며, 당시 이 점수를 산출했다고 주장하지 않는다. 관측이 없는 과거 날짜는 자료 없음이다. 현재 계약 상태를 과거로 소급해 중간 진척도를 만들지 않는다.

GitHub Pages의 앱 관측 기록은 게시 시점에 포함된 원장 관측 하나를 제공한다. 별도 **공식 과거 자료** 탭은 LBNL 2020–2025년 연간 원장과 NYISO 2023–2026년 보관본·취득본의 당시 상태로 점수를 재계산한다. 각 점에 평가 수·미산출 수와 출처 날짜를 함께 표시하며 모집단 변화와 초기 자료의 낮은 평가율을 숨기지 않는다. 서로 다른 기준일의 발전·저장·수용가 점수를 하나의 전국 과거 평균으로 합치지 않는다. [과거 자료 범위](HISTORY.md)를 참조한다.

반복 빌드는 같은 원장에 같은 점수를 산출하며 프로젝트 상태를 새로 수집한 것이 아니다. 실측 부하의 15분 목표 일정과 프로젝트 원장의 주간·월간 갱신은 별개이며, 프로젝트 원장의 자동 적재는 아직 활성화하지 않았다.

직접 평가 저장은 별도 API·DB 운영이 필요하다. Pages 내보내기는 단계 모형을 지원하고 서버 계산과 전체 신청의 점수·합계를 대조한다. 저장된 직접 평가 이력은 아직 지원하지 않으므로 그런 이력이 있는 DB를 내보내려 하면 중단한다.

완료·철회된 발전·저장 사업 전체와 개별 프로젝트의 전체 생애 이력은 추가 적재가 필요하다. 과거 시계열은 각 원장의 당시 활성 신청 집계다. NYISO 보존 원장에는 운영 4건·철회 17건도 있지만 현재 활성 평균의 분모에서 제외한다. 수용가 권역 비교의 동일 7건은 모든 시점에서 활성·평가 가능했던 선택 표본이며, 접수연도별 완료·철회까지 포함한 전체 생애 코호트 평균은 추가 구현이 필요하다.

같은 점검에서 ISO-NE 2건의 `Formal study agreement; not under construction.`을 공사 중으로 오인하던 분류도 수정했다. 이들은 공식 연구계약 진행으로 표시하며, 활성 개별 신청 점수 분모에 새로 추가하지 않았다.
