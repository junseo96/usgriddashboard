# 새 대시보드 오프라인 미리보기

Cloudflare 계정 연결 전에도 새 화면을 확인할 수 있도록 실제 로컬 관측 자료를 포함하는 단일 HTML 파일을 생성합니다. 브라우저로 파일을 열면 프로젝트 검색·유형/권역 필터·상세 요건·자료 출처·CSV 내려받기를 사용할 수 있습니다. HTML 파일에 코드와 데이터가 포함되어 있어 로컬 서버나 외부 CDN이 필요하지 않습니다.

이 파일은 **읽기 전용 미리보기**입니다. 배포된 사이트가 아니며, 평가 저장·자료 수집·자동 일정 실행은 지원하지 않습니다. 표시되는 관측시각은 실제 데이터베이스의 스냅샷 시각이고 내보낸 시각과 구분합니다. 최신 관측 1개만 포함하므로 그 이전 날짜에는 자료가 없다고 표시합니다. 원자료 기준일을 내보낸 날짜로 바꾸지 않습니다.

## 생성

앱 디렉터리에서 로컬 자료 초기화와 API 실행, 화면 빌드를 마친 뒤 실행합니다.

```sh
npm run seed:local
npm run dev:api
```

별도 터미널에서 실행합니다.

```sh
npm run build
node scripts/export-preview.mjs --output .state/grid-atlas-preview.html --save-snapshot .state/preview-observation.json
```

기본 API는 `http://127.0.0.1:8789`이며 내보내기 스크립트에서만 사용합니다. HTML을 받은 사람이 해당 주소에 접속할 필요는 없습니다. 파일을 내려받은 뒤 Chrome·Edge·Safari 등 최신 브라우저로 엽니다.

동일 자료로 UI 빌드만 다시 반영할 때는 다음과 같이 실행합니다.

```sh
node scripts/export-preview.mjs --snapshot .state/preview-observation.json --output .state/grid-atlas-preview.html
```

`--snapshot`은 앞서 `--save-snapshot`으로 생성한, 신뢰할 수 있는 실제 API 관측 파일에만 사용합니다. 임의 JSON이나 과거 날짜를 만들어 넣지 않습니다.

## 정확성 범위

- 한 시점의 `knownAt`을 고정하고 실제 API의 모든 페이지를 가져옵니다. 페이지별 스냅샷 ID·내용 해시·총건수·합계를 대조합니다.
- 현재 버전은 모든 프로젝트의 5개 요건이 아직 미평가인 초기 데이터에 한해 내보냅니다. 실제 근거가 하나라도 존재하면 내보내기를 중단합니다. 평가 이력을 버리고 미평가로 보이게 하지 않습니다.
- 화면의 필터별 합계는 서버와 동일한 점수 계산 모듈로 산출합니다. 점수나 과거 관측을 생성하지 않습니다.
- 요청 쓰기는 차단하고, 자동 일정은 미리보기에서 미가동으로 표시합니다. 원본 출처 링크를 클릭하면 해당 외부 사이트로 이동할 수 있지만 미리보기 데이터는 갱신되지 않습니다.
- 생성 파일에는 공개 원장 자료가 포함됩니다. 관리자 토큰·로컬 데이터베이스·운영 자격증명은 포함하지 않습니다.
- 외부 웹폰트는 제외하고 운영체제의 기본 글꼴을 사용합니다. 네트워크 연결 없이 사용할 수 있도록 화면의 기능·자료에 필요한 파일을 모두 포함합니다.
- 평가 근거를 적재한 다음에는 모든 관련 평가와 실제 과거 관측을 안전하게 내보내는 기능을 먼저 확장하거나, 배포된 사이트를 사용해야 합니다.
